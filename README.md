# Termin

> Your friendly competitive programming contest reminder.

Termin is a lightweight personal tool that helps me keep track of upcoming competitive programming contests and reminds me before they start.

### Current

* Fetch upcoming contests
* Track contest schedules
* Send reminders

### Future

* More platforms
* Custom reminders
* Schedule change detection
* Calendar integration
* Conflict detection

**Early development**
If this turns out good, I will open contributions for the project.
